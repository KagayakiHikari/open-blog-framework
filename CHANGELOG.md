# Changelog

## 1.0.0 — 2026-10-29

The first and only planned public release of Open Blog Framework.

- Server-rendered articles, Markdown editing, drafts and scheduled publication.
- Tags, search, a UTC archive timeline, RSS and basic SEO.
- Configurable glass theme, responsive layouts and light/dark appearance.
- Administration, editor permissions, media management, session revocation and audit records.
- Independent Node.js and SQLite deployment, explicit release-file admission and security regression tests.
- MIT licensing with retained third-party notices, an English README and an optional Simplified Chinese README.

Features are frozen. No ongoing development, maintenance, issue-response deadline or future security patch is promised. Operators maintain their own installations or forks.
