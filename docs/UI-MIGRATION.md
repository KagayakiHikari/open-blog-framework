# 主题兼容性与验收

0.3.0-rc.1 默认主题提供全屏封面、滚动入场、浮动玻璃导航、文章画廊、阅读目录、标签搜索及同风格后台。design.json 管理虚构文案、本地资源、配色与导航；环境变量设置站点名称和初始主题。

安全修复应保留现有 UI 路由与交互。验收至少覆盖桌面和手机首页、文章列表／详情、标签、搜索、登录、后台文章与媒体、会话撤销、明暗切换及键盘菜单操作。只使用合成数据，截图不得携带密码或会话。

页面数据来自独立数据库，不能用静态截图替代功能。0.3.0-rc.1 新增 /archives 年份时间轴、筛选与分页，参见 ARCHIVES.md；没有归档参考截图，未宣称像素还原。音乐模块延期；评论或分类实体没有实现，不应标记为通过。

本地 SVG 示例的权属状态及图标许可见 ASSET-LICENSES.md。自定义图片、字体和上传内容需单独审核。所有媒体 URL 为公开资源，草稿不会使图片变成私密附件。

无 JavaScript 时保留连续页面与原生表单；减少动态效果分支、真实触屏和不同浏览器仍须按实际支持范围验证。具体执行证据保存在维护者的私人验证记录中。
