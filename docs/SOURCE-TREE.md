# 目录与交付范围

- src/：HTTP、配置、运行时校验、请求体预算、认证／内容／媒体、数据库和页面组件。
- migrations/：前向数据库迁移；002 使升级前会话全部失效并引入认证代际。
- public/：本站 CSS、浏览器交互和示例主题 SVG。
- scripts/：账号管理、迁移、语法、构建、扫描、许可及隔离验收工具。
- tests/：单元、HTTP 集成、竞态、慢请求、发布工具和设计边界测试。
- docs/：通用架构、安全、使用与许可说明。
- third-party/ 与 THIRD_PARTY_NOTICES.md：随选定图标再分发的完整许可。
- release-files.json：运行产物逐文件准入清单，新增交付文件必须明确审核并更新。

.git、node_modules、tests 和 CI 不进入运行产物。dist 包含清单允许的文件及 SHA-256 manifest；完整源码工程才提供完整测试，运行目录不是完整源码包。

数据目录由部署者独立初始化，含数据库、会话及媒体，禁止公开。运行产物不包含环境实值、数据库、日志、备份、证书或依赖二进制；自定义二进制素材需另行设计许可和发布审核规则。
