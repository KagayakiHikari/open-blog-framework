# 归档时间轴

`/archives` 使用现有文章表，只显示 `published` 且发布时间已到的文章；不暴露草稿、定时文章或其年份计数。不增加数据库结构、生产接口或后台写入能力。

- 按 UTC 年份分组、时间倒序，同一时间按文章 ID 稳定排序。
- `/archives?year=2024` 筛选年份，切换年份回到第一页；`page` 分页，每页最多 30 篇。
- 年份筛选支持 1970–9999，分页支持 1–10000；输入校验后使用参数化查询。
- 侧边年份导航与手机选择表单提供相同筛选能力；原生 details 支持键盘展开／收起，关闭 JavaScript 仍可读。
- JavaScript 仅增强“展开／收起年份”按钮，复用明暗主题；减少动态效果时关闭箭头动画。
- 复用本地背景、玻璃面板、导航、字体与颜色变量；没有引入第三方图片、字体或网络依赖。

这是独立主题的归档实现。没有可用的归档页参考截图，不能宣称已完成原界面的像素对照；具体视觉差异仍需维护者提供可公开的脱敏设计参考再确认。

音乐页面与播放器不在本次一次性发布范围，不承诺后续开发。本候选没有音乐文件、解密逻辑或专用远程接口。安装者可以通过 design.json 定制导航；已有自定义导航不会被强制覆盖，可自行添加 `/archives`。
